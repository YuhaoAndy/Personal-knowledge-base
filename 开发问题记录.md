# 开发问题记录

## 开发过程中遇到的问题和解决方案

---

### 问题1：pip install 很慢
**解决方案**：使用镜像源
```bash
pip install chromadb -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题2：MarkdownLoader 导入错误
**问题**：`ImportError: cannot import name 'MarkdownLoader' from 'langchain_community.document_loaders'`
**解决方案**：将 `.md` 文件改用 `TextLoader` 读取

### 问题3：langchain.text_splitter 导入错误
**问题**：`ModuleNotFoundError: No module named 'langchain.text_splitter'`
**解决方案**：改为 `from langchain_text_splitters import RecursiveCharacterTextSplitter`

### 问题4：ChromaDB 导入错误
**问题**：`ImportError: cannot import name 'ChromaClient' from 'chromadb'`
**解决方案**：使用 langchain_community 的 Chroma
```python
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import SentenceTransformerEmbeddings
```

### 问题5：ChatDeepSeek 导入错误
**问题**：`ImportError: cannot import name 'ChatDeepSeek' from 'langchain_community.chat_models'`
**解决方案**：使用 langchain-openai 的 ChatOpenAI，DeepSeek API 兼容 OpenAI
```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="deepseek-chat",
    api_key="你的API Key",
    base_url="https://api.deepseek.com"
)
```

### 问题6：f-string 语法错误
**问题**：`SyntaxError: unterminated triple-quoted f-string literal`
**解决方案**：删除 prompt 末尾多余的 `"`
